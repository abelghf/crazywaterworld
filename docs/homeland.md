# 家园与工坊

手动入口为 **杂项 → 家园**，自动化入口为 **挂机配置 → 基地 → 家园**。需要支持家园的游戏协议、当前配置表和已连接的账号。开放条件以当前角色、赛季和服务器状态为准；首次开启请在游戏完成家园引导。

页面显示家园等级、家具摆放数量、下一次升级条件、下一项科技、家园币余额与累计消费，以及工坊订单、各楼层打扫进度。刷新只读取状态，不执行游戏操作。挂机配置里的「只读预览」使用当前草稿计算可执行动作。

## 执行范围

- 领取每日免费工坊体力，以及工坊商店的免费每日商品。另开「整理并领取资源补给」后，可逐件取出奖励区物品、免费开资源箱、合并并领取资源棋子。
- 开启「自动完成工坊订单」后，默认按需从仓库取料、中转腾位、合成物品、生产原料及制造生产器，齐备后交单并继续处理新订单。锁定棋子不作为可交物品。
- 达到家园等级要求后开放下一层，逐项打扫。打扫会消耗家园币并给奖励。
- 按顺序升级科技，达到目标科技等级、等级门槛、预算或保留量限制后停止。
- 家园升级条件全部满足时升级，达到目标等级后停止。

自动化总开关和所有细项默认关闭，同时受「基地执行总开关」控制。订单仅保留一个开关，原有合成、生产、制造生产器、仓库存取子开关及工坊体力保留量、每日上限已移除；旧配置保留订单启停选择，废弃字段在读取、保存与导入时清理。挂机每批最多 4 个动作；累计执行达到 2 秒，或有其他操作排队时，在当前动作确认后结束这一批。批次因这些限制结束后，下一服务器秒即可重新检查和接续，不必等待完整主轮或默认的 300 秒检查间隔。每批重新读取棋盘，继续处理当前及新出现的订单，直到没有可执行动作、体力不足、家园币预算不足、生产器冷却或结果待确认，再按配置间隔检查；体力不足时仍可合成、交付已有材料。

独立的工坊、商店、消费计数和必要的英雄信息并发读取，全部返回后再并发读取物品与资源库存；失败时也等待同批请求结束。生产、合成、仓库存取和交单共用账号写入队列，逐步确认后继续，避免同时改动同一棋盘。上述接续同时适用于控制台挂机和 CLI 持续循环；显式有限轮数结束后不再继续。

仅开启每日免费领取时，当日确认完成后停止重复读取。手动操作不要求开启自动化，但仍受家园币预算和保留量限制。

## 工坊自动合成

在「挂机配置 → 基地 → 家园」开启「自动完成工坊订单」，自动使用现有棋盘与仓库材料。订单卡片展示下一步合成、步数或等待原因，也可手动执行单步操作。

规划优先处理限时订单，并保留其他订单已预留的成品。同一订单内部统一分配用料，允许用现有低级成品参与合成，只在最终能补齐该单所有需求时执行；每一步回读确认后重新规划，齐备后交单。半锁定棋子可作为合成目标，完全锁定格不参与。生产器仅在订单缺料时按必要的前置链制造；资源棋子的合并和领取由独立的资源补给开关控制。

规划使用 A* 搜索，以当前订单的合成、存入、取出总次数最少为目标；交单固定增加一次操作，不计入页面的备料步数。同种同状态棋子按数量压缩，实际执行时重新绑定棋子编号。估价忽略空间和半锁定限制，计算必需合成次数的下界；旧规划器提供完整可行方案作为上界，上下界相等即可证明最优。搜索允许重新打开成本降低的状态，避免启发式导致错误的最优结论。

最优性仅针对当前订单、当前棋盘与仓库空间及成品保留规则下的现有材料，不比较跨订单长期收益，也不包含随机生产的未来结果。每单搜索最多扩展 12,000 个节点，按 40,000 个已发现状态或 100 毫秒预算停止（在节点边界检查）；有完整方案时显示「可行方案，尚未证明步数最少」，搜索达到上限却没有完整方案时等待。页面与只读预览显示已证明的最少步数，搜索结果有界缓存且不复用旧棋子编号。

合成前联合比较棋盘内合成、仓库取料和中转的总步数。缺少工作格时自动暂存闲置普通棋子、稍后才用的原料、中间产物或成品；普通订单规划不移动生产器、体力瓶及锁定棋子。制造生产器和资源补给按下文范围使用必要的仓库物品。

现有材料足够时，中转会模拟整单的存入、取出和合成过程，逐步核算棋盘及仓库容量；只有能完成计划时才开始搬运，按计划逐件存取，不批量清空棋盘。中间产物在参与后续合成前取回，交单前确保全部成品能回到棋盘；暂时用不到的物品留在仓库，后续按订单需求取回，不自动恢复原格子。不购买仓库容量，仓库满、容量未同步或缺少可暂存棋子时显示等待原因。订单到期时停止该单；材料不足时逐步生产补料。

## 按订单生产原料

订单缺料时自动使用生产器，按实际剩余工坊体力生产至订单完成、体力不足或其他条件阻止继续。工坊体力不设保留量与每日消费上限，页面保留今日消耗统计。家园币余额、累计消费和楼层等级门槛不会阻止工坊生产。

先尝试现有材料的完整合成方案。确实缺料时，从订单需求反推缺少的合成链，保留所有订单的现成品，优先执行有用的配对合成或取料。需要生产时，仅选择棋盘上已解锁、冷却结束且可能补充缺料的生产器，按实际产物库的概率比较每点体力可提供的有效原料。配置的 `libId` 决定产物，不以生产器名称、展示分组或等级猜测掉落。

每次只生产一件，再回读真实产物并重新规划；材料凑齐后切回 A* 合成并交单。随机副产物保留，后续按需使用；生成过程不标记为确定的最少步数。可以为下一次生产或配对暂存普通物品，包括需要稍后取回的中间产物；生产器仅按必要的前置合成链存取，资源棋子和锁定棋子不用于中转。体力不足、冷却中、仓库已满或没有对应生产器时说明原因并等待，不买体力或仓库容量。

生产接口依据 v77 客户端与协议：`DualCombineProduceRequest { cellId }` 返回 `cellId`、`newPiece` 和 `produceCell`；单次体力费用、次数和冷却来自 `DualCombineProduceCfg`，产物权重来自 `DualCombineProduceLibCfg`。有限次数的生产器用完可能消失，执行前读取服务端的 `produceLeft` 与 `produceCdTs`。缺少对应生产器时按下述规则制造，不盲目追求高等级。

`produceLeft` 按协议的有符号整数读取；配置 `count = 0` 的不限次数生产器兼容 `produceLeft = -1`，不会误判为同步失败。有限次数生产器仍要求非负余量，余量为 0 时等待，不因 `-1` 放宽限制。

## 按需制造生产器

自动订单包含按需制造生产器。例如缺水类订单原料时，可执行「打捞网产玻璃 → 合成海水过滤器 → 产水 → 合成并交单」，过滤器耗尽并由服务器移除后，仍有材料来源则重新制造。已有可用生产器时优先使用，不为了等级更高盲目合并。

规划从缺料反向查询实际产物库，为必要的生产器建立临时合成目标，保留所有真实订单现货，再用 A* 计算现有材料的制造与仓库存取步骤；材料仍不足时继续追溯上游生产器。只开放该目标的前置合成链，其他生产器保持原位；已消耗过次数的有限生产器不作为升级原料。合成链中的必要生产器允许按可用空间存取。每次只执行首步并重新读取状态，不跨批次复用棋子编号。

跨生产器追溯最多 8 层、48 个候选；每个临时目标的 A* 限于 1,500 个扩展节点、5,000 个状态及 15 毫秒。遇到循环依赖、配置不完整、缺料或空间不足时停止。随机产出与跨生产器选择属于有界规划，不宣称全局最优。

## 资源补给

「整理并领取资源补给」独立于交单开关，默认关闭。奖励区按服务器的 `chestCount` 与 `newestPieceCfgId` 逐件取出，至少有两个空格才开始取下一件，为后续生产或合并保留工作格；不会猜测奖励内容或购买补给。

资源箱只接受配置明确为零体力费用、有限次数且所有产物都是已识别资源棋子的生产器。目前包括体力箱、存钱罐、宝箱；实际剩余次数看服务器。每次开出一件后先重新规划，避免一次铺满棋盘。

体力瓶与家园币棋子优先合并不降低总收益的配对，最高级直接领取。缺少继续生产所需体力、缺少已启用打扫或科技所需家园币，或棋盘全满时，可领取低级资源；其余零散低级棋子保留待合并。补给默认可从仓库取出资源配对或领取所需棋子；补给不自动向仓库倾倒物品。领取体力后可继续订单生产，今日消耗统计不会清零。

v77 的可使用棋子没有独立数值奖励表，当前只识别体力瓶与家园币两类、且描述中明确写出领取数量的配置。使用 `DualCombineUsePieceRequest { cellId }` 后核对来源棋子消失、其他棋子和仓库不变，以及资源库存到账；有回执时还核对 `reward.asset`。开箱与奖励区取物也同时核对新增棋子及来源变化，未知结果持久保留，不能靠余额变化或奖励区数量减少单独认定成功。

## 家园币与升级条件

**累计消费家园币 = 家具购买 + 科技升级。** 该计数来自游戏，升级后不清零，不等于当前余额。打扫费用不计入游戏升级条件，但计入本工具的每日家园币用量。

新家园升至 2 级需要累计消费 100 家园币，科技在家园 2 级开放。起步阶段请先在游戏购买家具，随后可优先用科技推进累计消费。家园升级还可能要求玩家等级、已通过关卡、指定星级英雄数量，以及家园解锁后获得的功勋。

默认每日家园币预算为 500，保留量为 0。手动和自动打扫、科技共用预算；每日上限设为 0 时禁止家园币消费，免费领取和满足条件的家园升级仍可执行。保存设置或重启不会清零用量。

## 结果确认

消费发送前持久记录目标与额度。请求后回读科技、等级、任务、棋盘或商店状态；涉及家园币还要核对库存。超时不视为成功，也不立即重发。未知结果跨重连、跨日保留，未确认前暂停后续家园操作。

订单消失可能只是到期，因此还要核对该单所需棋子已经消耗。昨日免费领取结果若无法确认，换日后保留未知历史，允许领取新一天的独立免费额度。

合成回读同时核对源格清空、目标格升级与原料消耗；订单到期本身不能确认合成成功。不购买付费体力、仓库容量、商品或家具，也不处理装修、英雄入住与拜访。

生产发送前持久占用体力额度，回执中的新棋子编号和格子随记录保存；回读须确认原空格出现了产物库内的新棋子、原有材料完整保留及生产器状态相符。只有体力下降或订单到期不能确认生产。响应丢失时按完整棋盘基线核对；无法确认则跨重连、跨日防重并暂停后续家园操作。

仓库中转须同时确认源格清空与同编号、同种类的棋子进入仓库；超时后跨重连与跨日保留未知记录，确认前不继续搬运。页面显示仓库用量、计划暂存数量及下一步中转操作。

## 离线验证

`npm run test:homeland` 验证真实协议编解码、业务规则、预算、未知结果、重连、并发查询的乱序返回与失败排空、分批接续、账号队列和 HTTP 边界。`npm run test:homeland:browser` 验证真实控制台页面和手机布局。测试使用隔离数据目录及假游戏服务端，不连接真实游戏账号。
